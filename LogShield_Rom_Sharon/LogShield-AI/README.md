# LogShield AI**LogShield AI** is a machine-learning based cybersecurity project for detecting suspicious login attempts in authentication logs. The system analyzes login-related features and uses an **Isolation Forest** anomaly detection model to identify behavior that may indicate attacks such as **Brute Force** and **Credential Stuffing**.## Project GoalThe goal of this project is to demonstrate how AI can support cybersecurity monitoring by automatically identifying anomalous login events. Instead of manually reviewing large amounts of log data, the system ranks suspicious events and helps security teams focus on the most risky activity first.## Cybersecurity ScenarioThe project focuses on suspicious authentication behavior, including:* Many failed login attempts in a short time window.* Multiple usernames attempted from the same source IP address.* Login attempts during unusual hours.* High geographic risk or poor IP reputation.* High login velocity within one hour.* Low login success ratio.* Login attempts from a new or changed device.These patterns are relevant to common credential-based attacks, especially **Brute Force** and **Credential Stuffing**, which are mapped to MITRE ATT\&CK technique **T1110 - Brute Force**.## Machine Learning ApproachThe model used in this project is **Isolation Forest**.Isolation Forest is suitable for anomaly detection because it learns the structure of normal behavior and identifies events that are statistically easier to isolate. In this project, the model is trained mainly on legitimate login activity and then used to detect suspicious login events.## DatasetThe project uses a synthetic login-log dataset generated by `generate\\\_dataset.py`.Dataset size:* Total rows: **2760*** Legitimate login events: **2400*** Anomalous login events: **360**The dataset contains both normal login activity and attack-like scenarios such as Brute Force and Credential Stuffing.## Features Used by the Model|Feature|Description||-|-||`failed\\\_attempts\\\_10m`|Number of failed login attempts in the last 10 minutes||`unique\\\_usernames\\\_10m`|Number of different usernames attempted from the same source||`login\\\_hour`|Hour of the login attempt, from 0 to 23||`geo\\\_risk\\\_score`|Geographic risk score||`ip\\\_reputation\\\_score`|Risk score of the source IP address||`login\\\_velocity\\\_1h`|Login attempt rate within one hour||`success\\\_ratio\\\_1h`|Ratio of successful logins within one hour||`device\\\_change\\\_flag`|Indicates whether the login came from a new device|## Project Structure```textLogShield-AI/├── README.md├── assets/│   ├── confusion\\\_matrix.png│   ├── requirements.txtpython generate\\\_dataset.pypython train\\\_model.pypython evaluate\\\_model.py```To run inference on a single suspicious login event:```bashpython main.py --failed 20 --users 3 --hour 2 --geo-risk 80 --ip-reputation 90 --velocity 100 --success-ratio 0.05 --device-change 1```To run inference on the full dataset:```bashpython main.py --dataset```## Updated log pipeline.* More features can be added, such as country, browser, user-agent, device fingerprint, and historical user behavior.## Future WorkPossible future improvements:* Connect the system
